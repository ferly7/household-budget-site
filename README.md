HomeLedger is a household budget planner that runs entirely in the browser: a live dashboard with income, spending and savings rate, full transaction tracking, monthly budgets with over-budget warnings, savings goals, and reports with charts and saving tips based on your own numbers. All data stays in localStorage on your device.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a browser.
